## 📌 ¿Qué es?

**Desarrollo de Interfaces Web** se centra en la parte visual y en la experiencia de usuario de una aplicación web.

Durante el módulo aprenderemos a organizar información, construir interfaces coherentes y adaptar los diseños a diferentes dispositivos.

## 🎯 Contenidos
