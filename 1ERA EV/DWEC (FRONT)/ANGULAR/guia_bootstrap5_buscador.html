Bootstrap 5

Rejilla · Utilidades · Componentes · Formularios · JavaScript · Iconos · Plantillas

Todo lo que se usa de Bootstrap 5.3 con código listo para copiar y pegar. Cada bloque de código funciona por sí solo si tienes Bootstrap cargado (ver apartado 1). En la versión HTML tienes un buscador en tiempo real y un botón Copiar en cada bloque.

1. Instalación y plantilla base

1.1. Plantilla HTML con CDN

La forma más rápida: copia esto en un index.html y ya tienes Bootstrap, sus componentes con JavaScript y los iconos.

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi web</title>
  <!-- CSS de Bootstrap -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- Iconos (opcional) -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
  <!-- Tu CSS, SIEMPRE después de Bootstrap para poder sobrescribirlo -->
  <link href="css/styles.css" rel="stylesheet">
</head>
<body>

  <h1 class="text-center mt-5">¡Hola, Bootstrap!</h1>

  <!-- JS de Bootstrap (incluye Popper: dropdowns, tooltips, popovers) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script src="js/main.js"></script>
</body>
</html>

Sin la línea del <meta name="viewport"> la web no es responsive en el móvil. Y sin el bootstrap.bundle.min.js no funcionan: modal, dropdown, navbar hamburguesa, carousel, collapse, accordion, offcanvas, tabs, toasts, tooltips ni popovers.

1.2. Con npm (y en Angular)

npm install bootstrap bootstrap-icons

En Angular, añade los archivos en angular.json → projects > tu-app > architect > build > options y reinicia ng serve:

"styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "node_modules/bootstrap-icons/font/bootstrap-icons.min.css",
  "src/styles.css"
],
"scripts": [
  "node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"
]

Alternativa rápida en Angular: pegar los <link> y el <script> del CDN en src/index.html.

También se puede importar desde el styles.css global: @import 'bootstrap/dist/css/bootstrap.min.css';

1.3. Cómo se leen las clases de Bootstrap

Casi todas las clases siguen el patrón propiedad-{lado}-{breakpoint}-{valor}:

Clase Se lee
mt-3 margin-top de tamaño 3
px-md-5 padding horizontal (x) de 5, desde md hacia arriba
col-lg-4 ocupa 4 de 12 columnas desde lg
d-none d-md-block oculto en móvil, visible (block) desde md
text-bg-primary fondo primary con texto de contraste automático

2. Breakpoints, contenedores y rejilla (grid)

2.1. Breakpoints

Bootstrap es mobile first: una clase sin breakpoint se aplica a todos los tamaños; con breakpoint, se aplica desde ese tamaño hacia arriba.

Breakpoint Infijo Desde Dispositivo típico
Extra small (ninguno) 0 px Móvil vertical
Small sm 576 px Móvil horizontal
Medium md 768 px Tablet
Large lg 992 px Portátil
Extra large xl 1200 px Escritorio
Extra extra large xxl 1400 px Pantalla grande

Si necesitas el mismo corte en tu CSS:

@media (min-width: 768px) {   /* md hacia arriba */
  .hero { height: 60vh; }
}

2.2. Contenedores

Clase Comportamiento
container Ancho fijo centrado que cambia en cada breakpoint
container-fluid Siempre 100 % del ancho
container-md 100 % hasta md; a partir de md, ancho fijo 
<div class="container">…contenido centrado…</div>
<div class="container-fluid bg-dark text-white py-3">…barra a lo ancho…</div>

2.3. Filas y columnas

La rejilla tiene 12 columnas. Siempre: container → row → col.

<div class="container">
  <div class="row">
    <div class="col">1/3</div>
    <div class="col">1/3</div>
    <div class="col">1/3</div>
  </div>
</div>

Columnas responsive (lo que más cae): 1 columna en móvil, 2 en tablet, 3 en portátil, 4 en escritorio:

<div class="row g-4">
  <div class="col-12 col-md-6 col-lg-4 col-xl-3">Tarjeta</div>
  <div class="col-12 col-md-6 col-lg-4 col-xl-3">Tarjeta</div>
  <div class="col-12 col-md-6 col-lg-4 col-xl-3">Tarjeta</div>
  <div class="col-12 col-md-6 col-lg-4 col-xl-3">Tarjeta</div>
</div>

Lo mismo, más corto, con row-cols (las columnas hijas solo llevan col):

<div class="row row-cols-1 row-cols-md-2 row-cols-lg-4 g-4">
  <div class="col">Tarjeta</div>
  <div class="col">Tarjeta</div>
  <div class="col">Tarjeta</div>
  <div class="col">Tarjeta</div>
</div>

Layout típico sidebar + contenido:

<div class="row">
  <aside class="col-md-3 bg-light">Menú lateral</aside>
  <main class="col-md-9">Contenido</main>
</div>

2.4. Opciones de las columnas

Clase Qué hace
col Reparte el espacio libre a partes iguales
col-6 Ocupa 6/12 (la mitad)
col-auto Ocupa solo lo que mide su contenido
offset-md-3 Deja 3 columnas vacías a la izquierda (desde md)
order-first / order-last / order-md-2 Cambia el orden visual
ms-auto Empuja la columna a la derecha
g-0 … g-5 Separación (gutter) entre columnas; gx-* horizontal, gy-* vertical
justify-content-center (en row) Centra las columnas horizontalmente
align-items-center (en row) Centra las columnas verticalmente

<div class="row justify-content-center">
  <div class="col-12 col-md-6">Formulario centrado</div>
</div>

<!-- Imagen arriba en móvil, a la derecha en escritorio -->
<div class="row align-items-center">

  <div class="col-md-6 order-md-1"><h2>Título</h2><p>Texto…</p></div>
</div>

<!-- Filas anidadas: dentro de una col se puede abrir otra row -->
<div class="row">
  <div class="col-8">
    <div class="row">
      <div class="col-6">A</div>
      <div class="col-6">B</div>
    </div>
  </div>
</div>

3. Utilidades de espaciado y tamaño

3.1. Margin y padding

Formato: {m|p}{lado}-{bp}-{tamaño}

Propiedad Lado Tamaño
m margin t top · b bottom 0 = 0
p padding s start (izq.) · e end (der.) 1 = .25rem (4 px)
x izq. + der. 2 = .5rem (8 px)
y arriba + abajo 3 = 1rem (16 px)
(nada) = los 4 lados 4 = 1.5rem (24 px)
5 = 3rem (48 px) · auto (solo margin) 
<div class="mt-5 mb-3 px-4 py-2">…</div>
<div class="mx-auto" style="width: 300px;">Centrado horizontalmente</div>
<div class="p-2 p-md-4 p-lg-5">Más padding cuanto más grande la pantalla</div>
<div class="ms-auto">Empujado a la derecha (dentro de un flex)</div>

En Bootstrap 5 ya no existen ml-*, mr-*, pl-*, pr-* (eran de Bootstrap 4). Ahora es ms / me / ps / pe (start / end).

3.2. Gap (separación en flex y grid)

<div class="d-flex gap-3">…</div>
<div class="d-grid gap-2">…</div>
<div class="d-flex flex-wrap row-gap-2 column-gap-4">…</div>

3.3. Ancho, alto y viewport

Clase Valor
w-25 w-50 w-75 w-100 w-auto ancho en % del padre
h-25 h-50 h-75 h-100 h-auto alto en % del padre
mw-100 / mh-100 max-width / max-height 100 %
vw-100 / vh-100 100 % del ancho / alto de la ventana
min-vw-100 / min-vh-100 mínimo el ancho / alto de la ventana 
<section class="min-vh-100 d-flex align-items-center justify-content-center">Pantalla completa</section>
<button class="btn btn-primary w-100">Botón a todo el ancho</button>

4. Display, flexbox y posición

4.1. Display (mostrar / ocultar)

d-{bp}-{valor} con valores none, inline, inline-block, block, grid, inline-grid, flex, inline-flex, table, table-cell, table-row.

Quiero… Clases
Ocultar siempre d-none
Ocultar solo en móvil d-none d-md-block
Mostrar solo en móvil d-block d-md-none
Ocultar solo en lg d-lg-none d-xl-block
Ocultar al imprimir d-print-none
Oculto pero ocupando espacio invisible (y visible)
Oculto pero leído por lectores de pantalla visually-hidden

4.2. Flexbox

<div class="d-flex justify-content-between align-items-center">
  <span>Izquierda</span>
  <span>Derecha</span>
</div>
Categoría Clases (todas admiten breakpoint: flex-md-column…)
Activar d-flex, d-inline-flex
Dirección flex-row, flex-row-reverse, flex-column, flex-column-reverse
Eje principal justify-content-start · -end · -center · -between · -around · -evenly
Eje cruzado align-items-start · -end · -center · -baseline · -stretch
Un solo hijo align-self-start · -end · -center · -baseline · -stretch
Varias líneas flex-wrap, flex-nowrap, flex-wrap-reverse, align-content-*
Crecer / encoger flex-fill, flex-grow-1, flex-grow-0, flex-shrink-0, flex-shrink-1
Orden order-0 … order-5, order-first, order-last
Separación gap-0 … gap-5 
<!-- Centrar cualquier cosa en vertical y horizontal -->
<div class="d-flex justify-content-center align-items-center" style="height: 300px;">
  <div>Centrado</div>
</div>

<!-- Columna en móvil, fila en escritorio -->
<div class="d-flex flex-column flex-md-row gap-3">
  <div class="flex-fill p-3 border">A</div>
  <div class="flex-fill p-3 border">B</div>
</div>

<!-- Footer pegado abajo -->
<body class="d-flex flex-column min-vh-100">
  <main class="flex-grow-1">…</main>
  <footer class="py-3 bg-dark text-white">…</footer>
</body>

4.4. Posición

Clase Qué hace
position-static · -relative · -absolute · -fixed · -sticky Tipo de posición
top-0 top-50 top-100 (también bottom-, start-, end-) Desplazamiento 0 / 50 / 100 %
translate-middle Centra respecto a su punto (-x / -y para un eje)
fixed-top / fixed-bottom Fijo arriba / abajo de la ventana
sticky-top (y sticky-md-top…) Se queda pegado arriba al hacer scroll
z-n1 z-0 z-1 z-2 z-3 z-index 
<!-- Badge de notificación en la esquina de un botón -->
<button class="btn btn-primary position-relative">
  Mensajes
  <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">
    99+
  </span>
</button>

<!-- Elemento centrado dentro de su padre -->
<div class="position-relative" style="height: 200px;">
  <div class="position-absolute top-50 start-50 translate-middle">Centro</div>
</div>

  html.dataset.bsTheme = html.dataset.bsTheme === 'dark' ? 'light' : 'dark';
});

Paso 3 — El JavaScript que lo activa: al enviar, si no es válido, cancela el envío; y siempre añade was-validated para que se pinten los colores.

document.querySelectorAll('.needs-validation').forEach(form => {
  form.addEventListener('submit', event => {
    if (!form.checkValidity()) {
      event.preventDefault();
      event.stopPropagation();
    }
    form.classList.add('was-validated');
  });
});

Validación manual (tus propias reglas, p. ej. contraseñas iguales): quita was-validated y pon tú las clases is-valid / is-invalid en cada input.

const pass = document.querySelector('#pass');
const repite = document.querySelector('#repite');

repite.addEventListener('input', () => {
  const ok = repite.value === pass.value && repite.value !== '';
  repite.classList.toggle('is-valid', ok);
  repite.classList.toggle('is-invalid', !ok);
});
<input type="password" class="form-control" id="repite">
<div class="invalid-feedback">Las contraseñas no coinciden.</div>

En Angular no uses el JS de arriba: pon [class.is-invalid]="campo.invalid && campo.touched" y el invalid-feedback dentro de un @if. (Mira la guía de Angular, apartados 10 y 12.)
