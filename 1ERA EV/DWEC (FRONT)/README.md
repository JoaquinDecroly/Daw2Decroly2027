## 📌 ¿Qué es?

**Desarrollo Web en Entorno Cliente** trabaja la parte de la aplicación web que se ejecuta directamente en el navegador.

JavaScript será la herramienta principal para conseguir que una página pueda **responder a las acciones del usuario y modificar dinámicamente su contenido**.
