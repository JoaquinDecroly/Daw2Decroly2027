## 👋 Bienvenido

Este repositorio reúne las **actividades, ejercicios, prácticas y proyectos** realizados durante **2º de Desarrollo de Aplicaciones Web** en el curso **2026/2027**.

Más que una colección de archivos, es un recorrido por las diferentes etapas del desarrollo web:

<div align="center">

### 🎨 Diseñar → ⚡ Programar → ⚙️ Construir → 🚀 Desplegar → ☁️ Publicar

</div>

# 📚 Módulos

<div align="center">

|     | Módulo | Área | Tecnologías |
| :-: | :--- | :--- | :--- |
| 🎨 | **DIW** | Interfaces Web | `HTML` `CSS` `UI/UX` |

| ⚙️ | **DWES** | Backend | `PHP` `Java` `Spring Boot` |

### 🎨 DIW · Diseño de Interfaces Web

> Diseñar interfaces claras, atractivas y adaptables.

`HTML` `CSS` `Responsive` `Accesibilidad` `Tipografía` `Color` `UI/UX`

📂 **[Abrir módulo →](./1ERA%20EV/DIW%20%28INTERFACES%20WEB%29)**

---

### ⚡ DWEC · Desarrollo Web en Entorno Cliente

> Conseguir que la web responda al usuario.

`JavaScript` `DOM` `Eventos` `Formularios` `JSON` `Bootstrap`

📂 **[Abrir módulo →](./1ERA%20EV/DWEC%20%28FRONT%29)**

---

### ⚙️ DWES · Desarrollo Web en Entorno Servidor

> Construir la lógica que mueve la aplicación.

`PHP` `Java` `Spring Boot` `REST` `HTTP`

📂 **[Abrir módulo →](./1ERA%20EV/DWES%20%28BACK%29)**

---

### 🚀 DAW · Despliegue de Aplicaciones Web

> Llevar el código hasta una aplicación funcionando.

`Servidores` `Docker` `Contenedores` `Configuración` `Deploy`

📂 **[Abrir módulo →](./1ERA%20EV/DAW%20%28DESPLIEGUE%29)**

---

### ☁️ OP-CN · Computación en la Nube

> Entender dónde y cómo se ejecutan los servicios modernos.

`Cloud` `IaaS` `PaaS` `SaaS` `Virtualización`

📂 **[Abrir módulo →](./1ERA%20EV/OP-CN%20%28COMPUTACIÓN%20NUBE%29)**

---

### 🧠 DASP · Digitalización aplicada a los sectores productivos

> Comprender cómo la digitalización transforma los procesos y modelos productivos.

`Digitalización` `Transformación digital` `Tecnología` `Industria`

📂 **[Abrir módulo →](./1ERA%20EV/DASP%20%28DIGITALIZACIÓN%20SECTORES%20PRODUCTIVOS%29)**
